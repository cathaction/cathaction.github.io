    Per-site Results

    Evaluation

    • Ranking: case-macro Dice (per frame, averaged per sequence, then over sequences)
    • Also reported: clDice, precision, recall, HD95 (px), empty prediction rate
    • Human test set: 11,723 frames, 241 sequences, 4 hospitals (CLY, DHW, HTM, HXS)
    • Animal and phantom test set: 4,691 frames (animal 1,006, phantom 3,685)
    • Training data declared by each team is checked before publication

    Submission

    • Docker image, run offline on one GPU
    • Input: /input/image.nii.gz
    • Output: /output/segmentation.nii.gz (0 background, 1 catheter, 2 guidewire)
    • Method description and full list of training data
    • Dataset: CATHACTION, arXiv:2408.13126
